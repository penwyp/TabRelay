# TabRelay

**多设备标签接力，不覆盖本机工作区。** Chrome Manifest V3 扩展，使用自己的 WebDAV 保存设备独立快照。在工具栏浮窗中搜索、浏览各设备的窗口、标签和当前打开的标签组；确认后在本机新增窗口，随后回传合并后的实际工作区。

## 能做什么

- 自动采集普通窗口：URL、标题、顺序、置顶、活动标签、已打开标签组的名称/颜色/折叠状态。
- 每个浏览器 Profile 一个独立设备 UUID；不同设备分别发布，互不覆盖。
- 全窗口、单窗口、标签组或单标签恢复；预检后确认；原窗口不关闭。
- 来源标识去重防止 A → B → A 回环；相同 URL、不同来源默认保留。
- 持久化待发布快照和恢复日志；取消保留已创建窗口；安全条件满足时撤销。
- 最近有效非空恢复点、可配置历史保留；断网重试、认证错误、ETag 冲突显示。
- 域名黑名单、敏感查询参数移除、可选 AES-256-GCM 快照及正文对象加密。

不包含 Cookie、登录状态、表单、滚动、页面内存、前进后退历史、未打开的“已保存标签组”；不做远端标签自动打开或多主实时协同。

## 构建与安装

需要 Node.js 22+，Chrome/Chromium 120+。

```sh
npm ci
npm run check
```

在 Chrome 扩展管理页启用开发者模式，加载项目的 `dist/` 目录。点击工具栏图标打开实际的600×600浏览器浮窗；搜索、设备选择、恢复确认和进度均在浮窗内。设置仍单独打开浏览器标签页。

1. 点击设置，打开独立的浏览器设置标签页。设置设备名称、**WebDAV 基础目录**（推荐 HTTPS；HTTP 需勾选明文风险确认）、账号和应用专用密码。基础目录必须已经存在。
2. 授权该 WebDAV origin，开启自动同步。扩展只在用户点击保存/测试时请求该主机权限。
3. 同一 WebDAV 目录配置到另一台设备。若启用加密，所有设备填写相同加密口令。
4. 从设备列表选择快照和标签，点击预检，核对数量后确认恢复。

WebDAV 服务必须支持 `PROPFIND Depth: 1`、`MKCOL`、`GET`、`PUT`、`DELETE`、**强 ETag 和条件 PUT**。不支持强 ETag 的服务会明确拒绝更新，不会降级成不安全覆盖。目录/反向代理必须保留这些方法和 `If-Match`/`If-None-Match`。

## 安全与数据说明

- 生产构建支持 HTTPS 与 HTTP，默认推荐 HTTPS。HTTP 必须为当前主机明确勾选风险确认：账号、密码与未加密标签数据会以明文传输；可被同网络攻击者窃听或篡改。更换地址会重置确认。重定向不跟随；凭据只发送给本机明确配置的 origin 和目录。
- URL 可能包含敏感信息。默认移除 `access_token/token/auth/code/password/secret/session` 查询参数，可自行配置；**无法保证识别所有敏感参数**。不要将不该离开本机的域名同步到服务器。
- 无痕窗口不采集。只恢复 http/https，不恢复内嵌凭据、javascript/data/blob/file/chrome/其他扩展地址。
- 设置和加密口令保存在扩展本机 storage.local，仅受信任扩展上下文可访问；不使用 Cookie 或 history 权限。正文采集默认关闭，仅在用户明确同意后申请可选 scripting 权限和具体站点权限；不预授权所有网站。浏览器 Profile 被攻陷时，本机凭据与解锁口令不受保护。
- 加密使用随机 salt/IV、PBKDF2-SHA256 210,000 次派生及 AES-GCM；设备名称、数量和同步时间仍是明文。首次发布快照或尝试上传正文对象后，不支持在同一目录直接改加密口令，请使用新目录。旧快照仍需旧口令读取。
- 默认最多恢复 30 个窗口、1,500 个标签、500 个组、5 MB JSON。大批量恢复会消耗内存，先选择小范围。
- 冲突会暂停同步并要求检查 Profile 克隆或生成新的设备 ID。生成新 ID 不会删除旧设备远端文件。

## 恢复与重启边界

Chrome 没有跨窗口原子事务。TabRelay 在每次创建前持久化意图、创建后记录实际 ID。若中断恰好发生在两者之间，结果不确定时**不盲目重做**，提示保留当前结果、停止任务并检查。完整浏览器重启可能重新分配运行时 ID，此时拒绝自动续做/撤销旧任务；同一浏览器会话内的 Service Worker 重启可核对已记录进度后继续。

撤销仅针对本次创建、成员与 URL 未变化的窗口，并在每次关闭前复核。浏览器没有原子的“条件关闭”API，因此仍不能保证与用户在完全相同瞬间编辑窗口严格隔离；不确定时拒绝自动关闭。取消则只停止后续创建，已有窗口永远保留。

逻辑 ID 跨完整重启采用 URL、位置、窗口关系尽力重关联；完全相同 URL/位置的歧义无法绝对消除。此限制不会触发删除原有窗口。

## 私密窗口、固定标签与标签组

- 私密窗口指 Chrome 的无痕（Incognito）窗口。本扩展不允许无痕模式，也不会采集或恢复其中的内容，避免隐私数据进入 WebDAV。
- 固定标签记录 `pinned` 状态，恢复后按 Chrome 规则排列在新窗口左侧；同类标签保持原顺序，不改动已有窗口。
- 标签组记录名称、颜色、折叠状态及成员顺序，在新窗口中重建。固定标签不能同时属于标签组（Chrome 限制）。无标签组的标签仍保持未分组。
- 本机现有标签/窗口不会因导入被关闭或替换；恢复不是浏览器登录会话迁移，不包含 Cookie 或登录态。

## v2：浮窗搜索、正文与同步节奏

- 同步间隔可选 **5分钟 / 10分钟 / 30分钟 / 1小时 / 1天**，旧配置迁移默认10分钟。标签变化立即记录待同步，但不会用3秒防抖绕过所选间隔。手动同步及用户确认恢复后的合并发布是立即执行的例外；浏览器睡眠可能延迟自动触发。
- 新快照ID如 `20771031-190600Z-r000000000042`：UTC时间（Z），末尾单调revision用于同秒消歧和幂等重试。旧文件不重写，新版读取v1/v2；**所有设备都应升级到v2，旧版无法读取新schema2快照**。
- 浮窗打开/输入时自动加载全部可用设备的当前、恢复点及保留历史版本。5分钟刷新元数据；不可变历史和正文按引用复用，输入查询不逐个重下远端对象。
- 标题、URL、域名、组名及已加载正文支持中文/混合文字精确与包含匹配，无AI或模糊排名。先筛选再截断。相同URL、标题、正文、组/固定状态聚合展示，但每个设备/快照/窗口/标签来源都保留；恢复时选择明确来源。
- `清空本机搜索缓存`只清理本机加密索引并暂停自动回填；点击明确的「重新加载」才能重建。**不删除WebDAV历史或正文对象，不释放服务器磁盘。** 取消加载也保留已有部分并暂停；浮窗关闭不取消后台任务，重新打开可见进度。
- 本地索引使用64MiB已提交缓存上限的IndexedDB（控制清单另限2MiB），快照/正文去重保存并以会话密钥加密；storage.session只保存小清单与临时密钥。关闭浏览器丢弃密钥，下一次访问时删除旧密文，不持久保留可读正文。容量不足会明确显示未加载，绝不冒充完整搜索。
- 时间表示快照观察时间，不是访问时间；历史按版本数保留，不保证保留若干天。覆盖范围、失败、缺失正文、过时结果和容量上限都明确展示；未加载不等于没有结果。

### 正文采样与隐私

正文功能默认关闭。只有在独立设置页明确开启并授权具体HTTP/HTTPS站点后，才通过隔离脚本读取这些普通窗口中已经渲染的可见文字。跳过无痕窗口、黑名单、凭据URL、表单/密码框/输入框/可编辑区域/隐藏文字/脚本，不读取Cookie，不截图，不自动滚动或绕过登录。

**可见文章、聊天或页面正文仍可能包含秘密，无法自动保证脱敏。** 请仅允许你愿意同步内容的站点。采样是当前DOM文本，不是完整网页归档；懒加载、嵌入框架及未渲染内容可能缺失。每页最多20,000字符/60,000 UTF-8字节，并限制执行时间；每轮最多100页，后续周期按游标轮转，显示已采样/失败/跳过/待采样数量。页面导航或权限变化时拒绝绑定旧正文。

正文保存为每设备不可变去重对象，快照只含引用。启用加密时正文也加密，远端对象ID使用派生密钥HMAC而非明文指纹；恢复与再次发布保留原对象所有者。不含正文的旧快照仍可搜索标题/URL并恢复。

本版**不自动删除远端正文对象**，避免并发写入/失败扫描误删被历史引用的数据。每设备客户端限制1,000个唯一正文对象；达到上限后正文显示不可用原因，元数据仍可同步。该上限不是跨克隆设备原子配额。历史JSON裁剪可能留下正文孤儿；清理服务器空间需另行安全维护，不能用清本机缓存代替。详情见[数据模型与迁移设计](docs/data-model-v2.md)。
