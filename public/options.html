此连接使用未加密的 HTTP

WebDAV 用户名、应用密码及请求会以明文传输，网络中的其他人可能截获或篡改。即使启用快照加密，登录凭据仍不受保护。建议只在可信隔离网络中使用。

正文搜索（默认关闭）
开启后，将读取你明确授权站点的可见正文，用于跨设备正文搜索。可见文字可能包含商业秘密、聊天或其他敏感信息；请只授权你愿意采集的站点。不采集表单字段、密码框、可编辑区域或无痕页面，不承诺能识别所有敏感文字。

仅接受明确的 HTTP / HTTPS 源（协议＋主机＋可选端口），不允许通配符或路径。点击保存时只申请这些站点及 scripting 权限；不会申请所有网站。

正文按快照的加密策略保存：设置加密口令后加密；未设置则不加密。远端正文对象最多保留 1000 个，达到上限停止新增，不自动清理。关闭采集或清空本机搜索缓存，不会删除远端正文或快照。

隐私与保留策略

每行一个域名，同时排除其子域名。

使用 AES-GCM 加密快照。口令保存在本机受信任扩展存储中；遗失后无法读取加密快照。设备名称与同步时间仍为明文。首次成功发布后不可在同一目录更换口令；如需更换，请使用新的 WebDAV 目录。

标签 URL 可能包含登录令牌等敏感信息。请使用可信 WebDAV，并配置需要移除的参数。不会同步 Cookie、表单字段或无痕窗口。正文只在上方明确开启并授权站点后采集。
