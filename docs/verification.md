# 验收与证据

最终状态以 GitHub Actions 对应 commit 的检查结果、`evidence/e2e-results.json` 和测试输出为准。

## 三个证据层级

1. TypeScript 与构建：生产代码类型检查、esbuild 打包，生产 manifest HTTP/HTTPS optional host。
2. 自动化单元/组件测试：真实业务模块，模拟 Chrome API、storage 和 fetch；覆盖 URL/结构/资源限制、隐私过滤、逻辑身份、来源去重、恢复/取消/撤销、持久 pending、并发锁、冲突及加密。
3. 真实 Chromium：独立 A/B Profile、实际浏览器窗口/标签/组、实际本机 DAV HTTP 服务；检查新增恢复、来源不变、回传、防回环、认证/断网、取消、空快照恢复点、冲突。通过时生成真实 UI 截图。

第 2 层不是第 3 层，也不是 macOS 或真实 WebDAV 服务实测。

## 环境说明

本次本地云命令沙箱禁止 Chromium 所需的 socket；申请普通运行权限后的命令在沙箱基础设施启动阶段失败，未绕过限制。提供 GitHub-hosted Linux CI 执行相同真实浏览器场景。如 CI 不可运行，应明确保留“未执行”，不能将模拟测试称作真实 E2E。

生产支持 HTTP 与 HTTPS；HTTP 通过用户明确保存/测试所选地址及普通浏览器主机授权配置，不再有额外风险复选框。真实浏览器测试使用 `--test` 单独构建，仅 manifest 预授予 127.0.0.1 主机权限，传输逻辑与生产一致，不使用 TLS 警告忽略参数。测试账户与页面都是合成内容。

## 主要验收项

- A/B 各自发布所有普通窗口，不共写 current。
- B 追加 A 窗口，原窗口 ID/URL 不变，组与置顶状态恢复。
- B 自动回传合并后的全量当前状态，A 的快照不变。
- 同来源同内容跳过，不把所有相同 URL 合并。
- 危险协议、损坏结构、超限输入在创建前拒绝/过滤。
- 401、403、超时、断网、条件冲突可观察；pending 持久化。
- 空 current 不覆盖非空 recovery。
- 中断日志、取消、原窗口保护、浏览器会话身份检查。
- 恢复过程本机改变后按实际采集回传，不拼接旧快照复活标签。

CI 当前真实 E2E并未覆盖所有 WebDAV 厂商、真实 HTTPS 证书链、操作系统级崩溃或 macOS 权限交互。单元故障注入覆盖的场景须单独注明。

## 搜索验收补充

搜索检索质量以小型人工标注语料的期望集合和 Recall@k 诊断为限，不推定真实用户历史的普遍召回率。关注中文/混合文字、精确包含、筛选先于截断、同 URL 不同来源、明确覆盖范围、仅已加载快照查询、失败/取消/设置重置、实时定位核验与历史结果恢复确认。真实 CI 截图与 JSON 说明本次实际执行项；没有加载或已被远端删除的版本不属于可检索语料。

## v2 浮窗、正文与迁移验证

新增测试必须区分实际 `chrome.action.openPopup` 目标与在600×600视口渲染同一popup页面；若真实action被环境拒绝，JSON保留错误，不宣称真实工具栏浮窗成功。正文测试只用合成页面：可见中英文正文与input/form/hidden/contenteditable/script等秘密标记，验证实际隔离脚本不写入这些标记，再通过WebDAV正文引用和中文片段完成搜索。

测试构建额外预授予loopback与scripting以避免CI交互权限弹窗；生产scripting为可选，并通过用户明确的站点授权按钮请求。生产/测试提取与传输逻辑相同，不绕过TLS。包括间隔到期/手动双阶段pending、可读ID/v1兼容、HMAC加密对象身份、正文去重、引用所有者、清缓存暂停、配置策略变更、缓存来源竞态与原有恢复安全回归。

容量回归使用100个独立20,000字符中文正文对象（约6MiB UTF-8），各被当前/恢复/历史引用。验证后半段唯一词可搜、正文不随版本倍增、session仅小清单、磁盘无明文、完整浏览器重启后丢钥清库。该语料证明不再受原3MiB/约50页限制，不代表无限历史或无容量上限。
